### 2. 三个核心层次

#### 工具层 (Tools)
Claude Code 通过**工具**与你的系统交互，不是直接执行代码：

| 类别 | 工具 | 用途 |
|------|------|------|
| 文件操作 | Read, Write, Edit | 读取、创建、修改文件 |
| 搜索 | Glob, Grep | 按模式查找文件、搜索内容 |
| 执行 | Bash | 运行终端命令 |
| 协作 | Agent | 启动子代理并行处理 |
| 管理 | Task* | 任务跟踪与管理 |
| 网络 | WebFetch, WebSearch | 获取网页、搜索信息 |

**关键理解**：Claude 不是"写代码给你"，而是"使用工具帮你完成任务"

#### 权限层 (Permissions)
每次工具调用都可能需要你的授权：

```
Claude 想要执行: Write(/path/to/file.js)
[允许] [允许本次会话] [拒绝]
```

**权限模式**：
- **默认模式**：敏感操作需确认
- **自动允许**：可配置特定操作自动通过
- **沙箱模式**：限制文件系统访问范围

#### 沙箱层 (Sandbox)
保护你的系统安全：
- 限制可访问的目录
- 危险命令需要确认
- 防止意外的破坏性操作

## 二、对话即编程

### 从"写代码"到"描述问题"

**传统编程**：
```python
# 你需要写出每一步
def add_user(name, email):
    user = User(name=name, email=email)
    db.session.add(user)
    db.session.commit()
    return user
```

**对话编程**：
```
"在用户注册时，将用户信息保存到数据库，需要处理邮箱重复的情况"
```

### Prompt 是新的编程语言

| 编程概念 | 传统代码 | Prompt |
|---------|---------|--------|
| 变量 | `x = 5` | "把这个值设为5" |
| 条件 | `if x > 0:` | "如果是正数的话..." |
| 循环 | `for i in range(10):` | "对每个文件都..." |
| 函数 | `def func():` | "每次遇到这种情况就..." |
| 抽象 | 类、模块 | 上下文、记忆、Skills |

### 对话编程的特点

1. **声明式** - 说"做什么"，不是"怎么做"
2. **容错性** - 表达不精确也能理解意图
3. **迭代性** - 可以逐步澄清和修正
4. **上下文相关** - 对话历史影响理解

## 三、"委托"vs"指令"思维

### 指令思维（AI IDE模式）

```
你："写一个函数，接收数组，返回最大值"
AI：返回一个函数
你："加上空数组处理"
AI：修改函数
你："写个测试"
AI：返回测试代码
你：手动复制粘贴，运行测试
```

**特点**：你指挥每一步，AI是打字员

### 委托思维（Native AI模式）

```
你："帮我实现一个找最大值的功能，要有测试，处理好边界情况"
Claude Code：
  1. 分析需求
  2. 创建文件
  3. 写实现代码
  4. 写测试代码
  5. 运行测试
  6. 发现问题并修复
  7. 确认完成
```

**特点**：你定义目标，AI规划并执行

### 思维转变对照表

| 维度 | 指令思维 | 委托思维 |
|------|---------|---------|
| 你的角色 | 操作者 | 决策者 |
| AI的角色 | 工具 | 代理人 |
| 你的输入 | 具体步骤 | 目标和约束 |
| 你的工作 | 写代码 | 审查代码 |
| 控制方式 | 微观管理 | 目标管理 |
| 效率来源 | AI打字快 | AI能自主解决问题 |

### 委托的艺术

**好的委托**：
- ✅ "实现用户登录功能，需要支持邮箱和手机号，有验证码"
- ✅ "这个API有bug，用户反馈登录后立即掉线，帮我排查修复"
- ✅ "把这个模块的代码重构一下，太乱了，保持功能不变"

**仍是指令**：
- ❌ "在第15行加一个if判断"
- ❌ "写一个叫validateEmail的函数"
- ❌ "把这个变量名从a改成userName"

**何时用指令**：
- 非常简单的改动
- 你比AI更了解具体该怎么做
- 需要精确控制输出格式

## 核心要点总结

1. **Claude Code = Claude模型 + 工具 + 权限系统**
2. **工具是Claude与系统交互的唯一方式**
3. **Prompt是新的编程语言，声明式、容错、迭代**
4. **从"指令"转向"委托"：定义目标，而非步骤**
5. **你的新角色：决策者和审查者，而非操作者**
