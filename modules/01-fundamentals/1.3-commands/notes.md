## 指令总览

Claude Code 的指令以 `/` 开头，分为以下几类：

```
┌─────────────────────────────────────────────────────────────┐
│                    Claude Code 指令分类                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  📊 环境感知        🧹 上下文管理       ⚙️ 配置管理          │
│  /help             /clear             /config              │
│  /status           /compact           /permissions         │
│                                                             │
│  🧠 记忆系统        💰 成本监控         🔧 高级功能          │
│  /memory           /cost              /vim                 │
│  /forget                              /terminal            │
│                    /bug               /mcp                 │
│                    /review            /login               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 一、环境感知指令

### /help - 帮助系统

**用途**：查看所有可用指令和功能说明

**使用场景**：
- 忘记某个指令怎么用
- 探索新功能
- 查看快捷键

```bash
/help          # 查看所有帮助
/help compact  # 查看特定指令帮助
```

---

### /status - 系统状态

**用途**：查看当前会话状态

**显示内容**：
- 当前工作目录
- 上下文使用量
- 会话配置
- 已连接的 MCP 服务器

**使用场景**：
- 检查上下文是否快满了
- 确认工作目录是否正确
- 排查配置问题

---

## 二、上下文管理指令 ⭐重要

### /clear - 清除上下文

**用途**：完全清除对话历史，重新开始

**使用场景**：
- 切换到完全不同的任务
- 上下文被无关信息污染
- 想要"干净"的开始

**注意**：
- 清除后无法恢复
- CLAUDE.md 等配置仍会加载
- 不会影响文件系统的改动

```bash
/clear  # 清除所有对话历史
```

---

### /compact - 压缩上下文 ⭐最常用

**用途**：智能压缩对话历史，保留关键信息

**工作原理**：
```
┌─────────────────────────────────────┐
│ 原始上下文（很长）                    │
│ - 第1轮对话的所有细节                 │
│ - 第2轮对话的所有细节                 │
│ - ...                               │
│ - 工具调用的完整输出                  │
└─────────────────────────────────────┘
                 │
                 ▼ /compact
┌─────────────────────────────────────┐
│ 压缩后上下文（精简）                  │
│ - 关键决策和结论的摘要                │
│ - 当前任务的核心上下文                │
│ - 最近的对话保持完整                  │
└─────────────────────────────────────┘
```

**使用场景**：
- 上下文接近上限时
- 长对话后想保持轻量
- 系统提示"上下文将被压缩"之前主动执行

**最佳实践**：
- 完成一个子任务后主动 compact
- 比 clear 更好，保留了上下文理解

```bash
/compact  # 压缩上下文
```

---

### /clear vs /compact 决策

```
需要减少上下文？
    │
    ├─ 之前的对话完全无关 ────→ /clear（完全重置）
    │
    └─ 之前的对话有参考价值 ──→ /compact（智能压缩）
```

## 三、配置管理指令

### /config - 配置管理

**用途**：查看和修改 Claude Code 配置

**常用操作**：
```bash
/config          # 查看当前配置
/config set key value  # 设置配置项
```

**可配置项示例**：
- 默认权限模式
- 自动压缩阈值
- 主题/显示设置

---

### /permissions - 权限管理

**用途**：查看和管理工具权限

**权限模式**：
- **default**：敏感操作需确认
- **trust**：信任更多操作自动执行
- **paranoid**：所有操作都需确认

**使用场景**：
- 批量操作时临时提升权限
- 敏感项目时降低权限
- 查看哪些操作被自动允许

```bash
/permissions           # 查看当前权限
/permissions reset     # 重置权限设置
```

---

## 四、记忆系统指令 ⭐重要

### /memory - 查看记忆

**用途**：查看 Claude Code 记住了什么

**记忆类型**：
| 类型 | 说明 | 示例 |
|------|------|------|
| user | 关于你的信息 | "用户是高级Go开发者" |
| feedback | 你的偏好反馈 | "不要在代码里加注释" |
| project | 项目相关信息 | "周四有代码冻结" |
| reference | 外部资源引用 | "Bug在Linear的INGEST项目" |

**使用场景**：
- 查看 Claude 对你/项目的理解
- 检查是否有过时的记忆
- 了解跨会话保留了什么

```bash
/memory  # 查看所有记忆
```

---

### /forget - 删除记忆

**用途**：删除特定记忆

**使用场景**：
- 记忆已过时
- 记忆有误
- 项目情况已变化

```bash
/forget  # 交互式选择要删除的记忆
```

---

## 五、成本监控指令

### /cost - 查看使用成本

**用途**：查看当前会话的 token 使用和估算成本

**显示内容**：
- 输入 tokens
- 输出 tokens
- 估算费用

**使用场景**：
- 监控长会话的成本
- 优化 prompt 效率
- 预算控制

```bash
/cost  # 查看成本统计
```

**成本意识培养**：
- 大文件完整读取 vs 部分读取
- 详细输出 vs 简洁输出
- 并行调用 vs 串行调用（并行可能更高效但单次成本更高）

## 六、高级功能指令

### /vim - Vim模式

**用途**：在Claude Code中使用Vim编辑器

**使用场景**：
- 需要复杂的文本编辑
- 习惯 Vim 操作的用户

### /terminal - 终端模式

**用途**：获取交互式终端

**使用场景**：
- 需要交互式命令（如 git rebase -i）
- 长时间运行的命令

### /mcp - MCP管理

**用途**：管理 Model Context Protocol 服务器连接

**使用场景**：
- 连接数据库
- 连接外部服务
- 扩展Claude Code能力

### /review - 代码审查

**用途**：对当前改动进行代码审查

### /bug - 报告问题

**用途**：报告 Claude Code 的 bug

## 七、快捷操作

### ! 前缀 - 快速执行命令

在提示中输入 `! command` 可以直接执行命令：

```bash
! git status      # 直接执行 git status
! npm test        # 直接执行 npm test
```

**与 Bash 工具的区别**：
- `!` 命令在你的终端直接执行，不经过 Claude
- 适合需要交互的命令（如登录）
- 输出直接显示，方便查看

## 核心要点

1. **上下文管理是关键** - 主动使用 /compact 保持轻量
2. **/compact 优于 /clear** - 保留理解，减少重复解释
3. **记忆系统跨会话** - 可以让 Claude "记住"你的偏好
4. **成本意识** - 定期 /cost 了解使用情况
5. **! 前缀很方便** - 快速执行不需要 Claude 参与的命令
