# 模块一：基础入门与观念重塑

## 学习目标
- 理解Claude Code的核心架构和工作原理
- 掌握基础工具链的使用
- 熟悉所有内置指令
- 能独立配置项目环境
- **完成从AI IDE到Native AI的观念转变**

## 预计时间
3小时

## 知识点

### 1.1 核心概念 (30分钟)
- Claude Code架构：工具、权限、沙箱
- 对话即编程的理念
- "委托"vs"指令"思维

### 1.2 基础工具链 (45分钟)
- Read/Write/Edit 文件操作
- Glob/Grep 搜索工具
- Bash 终端命令
- 工具的并行与串行

### 1.3 内置指令 (45分钟)
- 环境感知：/help, /status
- 上下文管理：/clear, /compact
- 配置管理：/config, /permissions
- 记忆系统：/memory, /forget
- 成本监控：/cost

### 1.4 项目配置 (45分钟)
- CLAUDE.md 编写规范
- settings.json 配置详解
- .claudeignore 规则
- 配置优先级

## 检查点
完成本模块后，你应该能够：
- [ ] 解释Claude Code与传统AI IDE的本质区别
- [ ] 为任意项目创建合适的CLAUDE.md
- [ ] 选择正确的工具完成文件操作和搜索
- [ ] 有效管理对话上下文
