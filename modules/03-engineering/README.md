# 模块三：工程实践与项目实战

## 学习目标
- 掌握Claude Code的Git工作流最佳实践
- 熟练使用任务管理系统
- 理解TDD在Native AI中的新实践
- 完成实战项目并建立评价反馈体系

## 预计时间
6小时

## 知识点

### 3.1 Git工作流集成 (45分钟)
- Git最佳实践
- 自动commit策略
- PR驱动开发
- Worktree隔离开发

### 3.2 任务管理系统 (45分钟)
- Task工具完整用法
- Plan模式
- 任务依赖管理

### 3.3 TDD配合 (30分钟)
- Native AI中的TDD
- 让Claude先写测试
- 红-绿-重构的AI版本

### 3.4 实战项目 (3小时)

#### 项目A：CLI Todo工具（入门）
- 命令行Todo管理
- TDD方式开发
- 评价：代码质量、测试覆盖、Git规范、Prompt效率

#### 项目B：API服务（中级）
- RESTful API开发
- 多Agent并行处理
- 评价：API设计、错误处理、Agent使用

#### 项目C：代码重构（高级）
- 遗留代码重构
- 渐进式执行
- 评价：安全性、改进幅度、过程管理

### 3.5 评价反馈体系 (15分钟)
- 自我评估维度
- 每日反思习惯

## 检查点
完成本模块后，你应该能够：
- [ ] 按规范管理Git工作流
- [ ] 使用Task系统管理复杂任务
- [ ] 完成至少2个实战项目
- [ ] 建立个人评价反馈习惯
